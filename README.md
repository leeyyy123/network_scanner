# 网络扫描器

一个基于Python的网络扫描工具，支持主机发现和端口扫描。

## 功能特性

### 扫描模式

| 模式 | 描述 | 扫描方式 | 端口数量 |
|------|------|----------|----------|
| 主机发现 | 仅检测存活主机，不扫描端口 | ICMP/TCP | - |
| 快速扫描 | 扫描常用端口 | TCP Connect | ~45个 |
| 标准扫描 | 扫描1-10000端口 | TCP Connect | 10000个 |
| SYN扫描 | 扫描1-10000端口 | TCP SYN | 10000个 |
| 指定端口 | 自定义端口扫描 | TCP Connect | 用户指定 |

### 快速扫描端口列表

- **文件传输**: 20, 21, 22, 23 (FTP, SSH, Telnet)
- **邮件服务**: 25, 110, 143, 465, 587, 993, 995 (SMTP, POP3, IMAP)
- **Web服务**: 80, 443, 8080, 8443, 8000, 8888, 5000, 9000 (HTTP, HTTPS)
- **数据库**: 3306, 1433, 1521, 5432, 6379, 27017, 9200 (MySQL, MSSQL, PostgreSQL, Redis, MongoDB)
- **Windows服务**: 135, 137, 138, 139, 445, 3389 (MS-RPC, NetBIOS, SMB, RDP)
- **其他服务**: 53, 67, 68, 123, 389, 636, 902, 5900, 1883, 5672, 2222 (DNS, DHCP, LDAP, VNC等)

### 指定端口输入格式

- 单个端口: `80`
- 多个端口: `80,443,22`
- 端口范围: `1-1000`
- 混合使用: `80,443,1-100,3306`

### IP地址输入格式

- 单个IP: `192.168.1.1`
- IP段: `192.168.1.1-192.168.1.10`
- CIDR格式: `192.168.1.0/24`

## 技术栈

- **GUI**: PyQt5
- **网络扫描**: scapy
- **并发处理**: concurrent.futures

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 扫描结果说明

| 状态 | 含义 |
|------|------|
| open | 端口开放，连接成功 |
| closed | 端口关闭 |
| filtered | 端口被过滤，无响应 |

## 注意事项

- SYN扫描需要管理员权限
- 端口扫描仅支持TCP协议
- 建议使用标准扫描或快速扫描进行日常使用
