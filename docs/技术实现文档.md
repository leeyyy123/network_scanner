# 网络扫描器 - 技术实现文档

## 一、项目概述

本项目是一个基于 Python + PyQt5 的图形化网络扫描器，功能参考 Nmap 实现，主要用于网络探测和安全检测。

### 开发环境
- **操作系统**：Windows 11
- **编程语言**：Python 3.11
- **GUI框架**：PyQt5
- **开发工具**：VS Code


### 2.2 端口扫描模块 (core/port_scan.py)

**功能**：扫描目标主机的开放端口

**实现方式**：
```python
def scan_port(host, port, timeout=1):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.settimeout(timeout)
    result = sock.connect_ex((host, port))
    sock.close()
    return result == 0  # 返回0表示端口开放
```

**特点**：
- TCP Connect 扫描方式
- 支持多种端口格式：
  - 单端口：`80`
  - 端口列表：`80, 443, 22`
  - 端口范围：`1-1024`
  - 混合：`22, 80, 443, 8000-8100`
- 多线程并发（默认100线程）

### 2.3 服务识别模块 (core/service_detect.py)

**功能**：根据端口号识别网络服务类型

**实现方式**：
```python
PORT_SERVICES = {
    80: 'HTTP',
    443: 'HTTPS',
    21: 'FTP',
    22: 'SSH',
    3306: 'MySQL',
    # ... 共50+常见端口映射
}

def get_service_by_port(port):
    return PORT_SERVICES.get(port, 'Unknown')
```

**支持的服务类型**：
| 类别 | 端口/服务 |
|------|-----------|
| Web服务 | HTTP(80), HTTPS(443), HTTP-Proxy(8080) |
| 远程连接 | SSH(22), Telnet(23), RDP(3389), VNC(5900) |
| 文件传输 | FTP(21), SFTP(115) |
| 数据库 | MySQL(3306), PostgreSQL(5432), Redis(6379), MongoDB(27017) |
| 邮件服务 | SMTP(25), POP3(110), IMAP(143) |
| 其他 | DNS(53), SMB(445), LDAP(389) 等 |

### 2.5 图形用户界面 (gui/)

**UI设计 (ui_main.py)**：
- 扫描配置区：IP输入、端口范围、超时时间、线程数

**主窗口逻辑 (main_window.py)**：

```python
class ScanThread(QThread):
    """后台扫描线程"""
    progress_updated = pyqtSignal(int, int, int)  # 进度信号
    log_message = pyqtSignal(str, str)            # 日志信号
    result_ready = pyqtSignal(str)               # 结果信号

    def stop(self):
        self._stop_flag = True  # 优雅停止
```

**特点**：
- 多线程扫描，不阻塞UI
- 实时显示扫描进度和结果
- 支持随时停止扫描
- 停止后保留已扫描结果

## 三、使用说明

### 3.1 安装依赖
```bash
pip install PyQt5>=5.15.0
```

### 3.2 运行程序
```bash
python main.py
```

### 3.3 使用方法

1. **目标IP/范围**：输入单个IP或IP段
   - 单IP：`192.168.1.1`
   - IP段：`192.168.1.1-10`

2. **端口范围**：设置要扫描的端口
   - 常用端口：`1-1024`
   - Web端口：`80, 443, 8080`
   - 自定义：`22, 80, 443, 8000-8100`

3. **高级选项**（可选）：
   - 超时时间：默认1秒
   - 线程数：默认50

4. **操作按钮**：
   - 开始扫描：启动扫描任务
   - 停止扫描：终止当前扫描
   - 清除结果：清空显示区域

## 四、技术亮点

### 4.1 多线程并发
使用 `ThreadPoolExecutor` 实现高效并发扫描：
```python
with ThreadPoolExecutor(max_workers=100) as executor:
    futures = {executor.submit(scan_port, host, port, timeout): port for port in ports}
    for future in as_completed(futures):
        result = future.result()
```

### 4.2 实时反馈
通过 PyQt5 信号槽机制实现实时更新：
```python
# 扫描线程发送信号
self.progress_updated.emit(progress, scanned, total)
self.result_ready.emit(result_text)

# 主线程接收信号更新UI
self.scan_thread.progress_updated.connect(self.on_progress_updated)
```

### 4.3 优雅停止
使用停止标志位而非强行终止线程：
```python
def stop(self):
    self._stop_flag = True  # 设置标志

def run(self):
    for port in ports:
        if self._stop_flag:  # 检查标志
            break
        # 扫描逻辑...
```
